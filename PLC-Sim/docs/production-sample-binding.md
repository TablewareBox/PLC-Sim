# 生产操作的样品绑定

PLC-Sim 0.2.11 的参考生产派发契约增加 labos.production-dispatch-binding/v3。v1/v2 原有五字段操作摘要含义保持；v3 必须显式携带 target，并把 sample_context 的 sample_id、reservation_id 与世界、操作、设备、动作、参数共同纳入 operation_sha256。样品上下文必须恰有两个非空字符串，不能降级到 v1/v2 后继续使用。

bind_dispatch 依据完整 operation 选择版本；若含样品而未给 target，只接受本地设备和设施设备同名，不猜测不同设备映射。校验拒绝添加、移除或替换样品/预留。完整派发身份、参数摘要、设备映射仍使用既有规则，样品不会被冒充为作业或进程身份。

公共模块只做绑定校验，不签发样品使用权限。设备包继续负责预留、物料、程序/结果所有权、隔离等原有行为；设施仍核验凭证、租约、撤销和设备恢复状态。恢复协调器通过既有版本集合识别 v3，沿用原停止证明协议。

专项验证旧版本兼容、双样品摘要、映射、格式拒绝，并通过原图普通驱动和真实CPU回环设施运行既有完整双样品流程及UNKNOWN停止。没有新增样品模型、修改启动JSON、构建安装或ROS/GPU运行。
